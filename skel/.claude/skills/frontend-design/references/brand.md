# Brand register: landing pages, marketing sites, portfolios, campaigns

Here the design *is* the product's first impression. The goal is a page that could only belong to this subject.

## The first viewport

Treat it as a poster, not a document.

- **Hero budget.** Usually: the brand or product name, one headline, one short supporting sentence, one call-to-action group, one dominant visual. Everything else (stats, feature lists, schedules, testimonials, logo clouds, promos) belongs further down.
- **Brand is unmistakable.** If you hide the nav and the page could belong to a competitor, the hierarchy is too weak. On branded pages, no headline should drown out the name.
- **One dominant visual idea.** A full-bleed image, a striking type treatment, a live product demo, an interactive moment. If the hero still works after removing the image, the image is too weak.
- **No clutter on top of the visual.** Avoid floating badges, stickers, chips and callout boxes stuck onto hero media.
- **Fit the viewport.** Sticky header plus hero content should fit the first screen at common desktop and mobile sizes. Use `min-height: calc(100svh - var(--header-h))` or overlay the header on the hero.
- **The big-number-plus-stats-plus-gradient hero is the template answer.** Use it only if numbers really are the story.

## Page as narrative

A good default sequence, adjusted to the subject:

1. **Hero** — who this is and what it promises
2. **Proof or context** — one concrete thing: the product in use, the place, a striking fact the user supplied
3. **Depth** — how it works, what makes it different, the story
4. **Trust** — real testimonials, customers, press, credentials (only if provided)
5. **Final action** — one clear thing to do next

Each section gets one job, one headline, and usually one short supporting sentence. Fewer, stronger sections beat many weak ones; six is plenty for most pages.

## Layout

- Vary section rhythm. Not every section should be "centered heading + three columns". Mix full-bleed media, narrow text columns, asymmetric splits, a single oversized quote.
- Use the grid as a tool, then break it once on purpose for the signature moment.
- Split-screen heroes only when the text sits on a calm, unified side.
- Carousels only when they advance a narrative. Users rarely see slide two.
- Structural devices (numbering, rules, eyebrows, labels) encode information. Number things only when they're a real sequence.

## Type

- A display face can carry the entire personality. Let headline type be large, tight-tracked or unusual when the thesis calls for it.
- Keep headlines to about 2–3 lines on desktop and readable at a glance on mobile.
- Body text stays plain and readable no matter how expressive the display is.

## Color strategies

Choose deliberately along a commitment axis:

- **Restrained** — neutral page, one accent used sparingly. Good for serious, premium, content-heavy.
- **Committed** — the brand color owns large areas (a full section, the hero background).
- **Full palette** — several colors with distinct roles. Needs real discipline to avoid noise.
- **Drenched** — the whole page lives inside one hue family. Bold and memorable; check contrast carefully.

## Imagery

- Prefer real, in-situ imagery: the product being used, the venue, the people, the material.
- If you need several moments, use several images, not a collage in one frame.
- Avoid images with their own embedded text, logos or UI chrome fighting the page.
- Generated or placeholder images should be clearly labelled as placeholders for the user to replace.

## Motion

Pick two or three moments, aligned to the motion dial:

- One entrance sequence for the hero (staggered, quick, finished in under a second).
- One scroll-linked or sticky storytelling moment, if it helps explain something.
- One interaction that sharpens affordance (a hover reveal, a meaningful transition).

Everything else stays still. Each motion should be noticeable in a quick screen recording and smooth on a mid-range phone, or it should go.

## Final checks for brand pages

- Is the brand unmistakable in the first screen?
- Is there one strong visual anchor, and is it specific to this subject?
- Can someone get the whole pitch from the headings alone?
- Is there exactly one primary action, repeated at the end?
- Would it still feel premium if every shadow and gradient were removed?
