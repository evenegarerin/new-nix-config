# Frontend Changes: Wireframe First

**Significant changes** (new page, new larger section, major layout restructuring):
1. Create a wireframe first.
2. Present it to the user and ask for confirmation.
3. Do not implement until the user approves.

**Minor changes** (changing labels or text, adding a single element at a clearly specified location):
- Skip the wireframe. Implement directly.

**When unsure** whether a change is significant, treat it as significant and wireframe first.
